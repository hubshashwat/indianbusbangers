Indian Bus Bangers

A nostalgic Indian bus ride web app with looping boarding and front-view bus animations, random-start banger playback, and links to classic Hindi travel songs.

Explore bus-worthy tracks including Barsaat Ke Mausam Mein, Tumsa Koi Pyaara, Yunhi Chala Chal Rahi, Neele Neele Ambar Par, and more.

View the open-source code on GitHub.
