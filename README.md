# Bus Bangers

A Vue/Vite UI app inspired by the supplied bus boarding reference video.

## What It Does

- Starts with guy/girl rider selection.
- Animates the selected rider boarding and sitting inside the bus.
- Reveals an Indian song menu with play/pause state, equalizer motion, volume,
  and track links.
- Uses the video thumbnail as a soft visual anchor for the bus interior.

## Commands

```bash
pnpm run dev
pnpm run build
```
